# VAMPLAUS — The Digital Archive · дизайн-система и план

Документ фиксирует решения Этапа 1. Он — источник правды для следующих этапов: новые
компоненты должны выводиться из него, а не придумываться заново.

---

## 1. Художественное направление

**Тезис.** Готическое окно с ажурным переплётом строилось циркулем и линейкой: чистая
геометрия ради трансцендентного. Это и есть «Between Logic and Imagination» в камне. Сайт
построен так же: строгая логика сетки и кода — ради воображения.

**Метафора.** Не портфолио, а *архив*. Разделы — это **фонды** (I–VII) с шифрами
(`VMP·LAB`), главная — **вестибюль** (Fond 0), навигация — **индекс**, интересы автора —
**предметный указатель**, как в конце книги. Пустые места не заполняются выдумкой: они
помечены как пустые ячейки каталога.

Пять источников и то, что берётся от каждого:

| Источник | Что берём | Где видно |
|---|---|---|
| Готика, старые библиотеки | стрельчатая арка, роза-окно, корешки книг, римские номера | портал на входе, эмблемы фондов, «полка» каталога |
| Японский минимализм | *ма* (пустота как материал), вертикальный текст, одна печать-ханко | вертикальные названия на корешках, асимметрия, один цвет |
| Редакционный дизайн | крупный serif, колонтитулы «§ 01», указатель с отточиями, колофон | все заголовки, Index of subjects, подвал |
| Технологический брутализм | моноширинные метаданные, видимые волосяные линии, квадратные углы, без теней | вся служебная типографика, рамки, приводные метки |
| Минимализм ОС | статус-бар с путём `~/archive/…` и часами, курсор, клавиатурные подсказки | верхняя панель, диалог индекса |

**Чего здесь нет намеренно:** градиентных фонов, стекла и размытия, теней, скруглений,
3D-объектов ради 3D, бесконечных анимаций, фиктивных фактов.

## 2. Дизайн-система

Все токены — в `src/app/globals.css` (`@theme`). Палитра Tailwind по умолчанию
**сброшена** (`--color-*: initial`), поэтому в коде физически нельзя использовать цвет вне
системы.

### Цвет

| Токен | Значение | Роль | Контраст |
|---|---|---|---|
| `void` | `#08090B` | фон — читальный зал ночью | — |
| `surface` | `#141519` | панели, открытый корешок | — |
| `raised` | `#1B1C21` | оверлеи (индекс, позже палитра и терминал) | — |
| `line` | `#303137` | волосяные линии, рамки | декоративно |
| `line-strong` | `#4A4B52` | рамки при наведении, кнопки | декоративно |
| `paper` | `#F0F0EA` | основной текст | 17.4:1 на void |
| `ash` | `#92949B` | вторичный текст | 6.6:1 на void, 6.0:1 на surface |
| `dust` | `#5D5F66` | только орнамент и разделители (`aria-hidden`) | 3.1:1 — не для текста |
| `oxblood` | `#7B1E2B` | **единственный цвет**: печать, заливки, выделение | paper на oxblood = 8.9:1 |
| `ember` | `#D0606B` | oxblood, поднятый для тёмного фона: фокус, мелкий акцентный текст | 5.3:1 на void |

Правило печати: `oxblood` ведёт себя как сургуч — на экране его мало, и каждое появление
что-то значит (текущая страница, открытый том, печать в центре розы). Сам `#7B1E2B` на
`#08090B` даёт лишь 1.96:1, поэтому как цвет текста и фокуса используется `ember`.

### Типографика — три голоса

| Голос | Шрифт | Роль |
|---|---|---|
| display | Cormorant Garamond (variable, normal + italic) | заголовки, инскрипционные капители, цитаты |
| sans | IBM Plex Sans (variable) | основной текст |
| mono | IBM Plex Mono 400/500 | метаданные, шифры, статус-бар, будущий терминал |

Все три поддерживают кириллицу: предзагружается только латиница, кириллица подгружается
по `unicode-range`, если появится русский текст.

Шкала (флюидная, через `clamp`): `display-xl` (имя на входе, до 14rem) → `display-l`
(заголовки фондов) → `display-m` → `display-s` → `lede` (serif-лид) → базовый 1rem →
`meta` (0.6875rem, mono, капс, трекинг 0.14em).

### Сетка и ритм

- `frame` — поля страницы: 20 / 40 / 56 px, максимум 100rem.
- `grid-archive` — 4 → 8 → 12 колонок. Композиция асимметрична (заголовок в 3 колонках,
  текст с 5-й), сама сетка — нет.
- Секции разделяются волосяной линией и большим вертикальным воздухом (96–144 px).

### Грамматика (утилиты и примитивы)

| Элемент | Где | Смысл |
|---|---|---|
| `meta` | утилита | любая служебная надпись |
| `ink-link` | утилита | подчёркивание «прописывается» слева направо |
| `leader` | утилита | отточия указателя |
| `spine-text` | утилита | вертикальный текст корешка |
| `SectionLabel` | `ui/section-label` | колонтитул «§ 01 —— Preface» |
| `Seal` | `ui/seal` | печать V: ханко + сургуч |
| `Emblem` | `ui/emblem` | линейные эмблемы фондов с одним «печатным» элементом |
| `CropMarks` | `ui/crop-marks` | типографские приводные метки |
| `PlaceholderBlock / Inline` | `ui/placeholder` | явная пустая ячейка вместо выдуманного контента |

**Эмблемы фондов** (циркуль и линейка, у каждой один элемент-печать, который загорается
`ember` при наведении/фокусе): I — ниша со стрельчатой аркой, II — квадрат, вписанная
окружность и диагональ (построение), III — тетрадные линейки с красным полем,
IV — каркасный куб, V — роза-окно, VI — ветвящийся стебель (сад), VII — запечатанное письмо.

### Движение

- Кривые: `ease-archive` (длинное спокойное торможение) и `ease-portal` (симметричная, для
  прорисовки линий).
- **Вход** — чистый CSS поверх серверного HTML. Решение «играть или нет» принимает inline-скрипт
  до первой отрисовки: только прямой заход на `/`, один раз за сессию, никогда при
  `prefers-reduced-motion`. Любое действие (клавиша, клик, скролл) завершает его. Без JS
  страница полная и статичная.
- **Переходы страниц** — React `<ViewTransition>` + View Transitions API: старая страница
  быстро гаснет, новая оседает на 14 px. Статус-бар неподвижен (фиксированная точка опоры).
- **Индекс** — нативный `<dialog>` (ловушка фокуса, Esc, возврат фокуса бесплатно), пункты
  появляются каскадом через Motion (`LazyMotion` + `domAnimation`, `reducedMotion="user"`).
- **Reduced motion**: глобально обнуляются длительности анимаций и переходов, View
  Transitions отключаются, вход не играет, курсор не мигает.
- Мигающий курсор в статус-баре останавливается после 4 циклов (WCAG 2.2.2).

### Характер фондов (реализуется на Этапе 2)

| Фонд | Характер |
|---|---|
| I Identity | досье: редакционный портрет, serif, заметки на полях |
| II Laboratory | брутализм: спецификации, mono-листинги, видимая сетка |
| III Classroom | тетрадь: линейки, нумерованные шаги, схемы на полях |
| IV Forge | мастерская: wireframe, рамки вьюпорта, приводные метки вокруг изображений |
| V Mind | библиотека: готический serif, карточный каталог, длинные цитаты |
| VI Journal | сад: заметки по степени зрелости, обратные ссылки |
| VII Contact | письмо: тихая страница, свёрстанная как корреспонденция |

## 3. Структура проекта

```
src/
  app/                      маршруты (App Router)
    layout.tsx              шрифты, метаданные, статус-бар, подвал, inline-скрипт входа
    page.tsx                Fond 0 — вестибюль
    identity/ … contact/    7 фондов (сейчас — заглушки из реестра)
    not-found.tsx           «Not in the catalogue»
    globals.css             токены, утилиты, вход, переходы, полка
    icon.svg                печать V
  content/                  ДАННЫЕ — единственное место, где живёт контент
    types.ts                модель: Fond, Subject, Placeholder
    site.ts                 факты о сайте и авторе (неизвестное = placeholder)
    fonds.ts                реестр фондов: порядок, тексты, эмблемы, статус
    subjects.ts             предметный указатель
  components/
    layout/                 status-bar, index-dialog, footer, clock, skip-link
    home/                   entrance, arch-portal, preface, catalogue, shelf, subject-index
    fond/                   fond-placeholder, fond-pager, metadata
    ui/                     seal, emblem, placeholder, crop-marks, section-label
    system/                 motion-provider, page-transition, intro*, inline-script
  lib/                      fonts, cn, roman
```

Принцип: компоненты читают типизированные записи из `src/content`. Добавить фонд, предмет
указателя, а с Этапа 2 — проект или заметку = добавить запись, не трогая компоненты.

## 4. План реализации

**Этап 1 — фундамент** ✅
Дизайн-система и токены, шрифты, архитектура контента, статус-бар, диалог индекса, подвал,
экран входа, главная (вход → предисловие → каталог-полка → предметный указатель), заглушки
семи фондов с пейджером, 404, переходы страниц, reduced motion, skip-link.

**Этап 2 — контент**
- Модель записей: `content/archive/*.ts` — проекты (тип, стек, год, статус, ссылки,
  изображения), строго типизированы; `content/journal/*.mdx` — заметки с frontmatter
  (зрелость: seedling / budding / evergreen, теги, связи).
- Страницы I–VII каждая со своим характером (таблица выше); детальные страницы записей
  `/laboratory/[slug]`, `/journal/[slug]` через `generateStaticParams`.
- Нужно от автора: биография, реальные проекты, ссылки, контакты, изображения, язык сайта
  (EN / RU / оба).

**Этап 3 — функции ОС**
- Command Palette (Ctrl/⌘ K): поиск по фондам, записям, заметкам, командам.
- Терминал: `help`, `whoami`, `projects`, `skills`, `contact`, `clear` — данные из `content/`.
- Archive Explorer: дерево фондов и записей с фильтрами и превью.
- System Log: лента обновлений из записей контента (даты добавления/изменения).

**Этап 4 — полировка**
- Анимации разделов, мобильные детали, переключатель движения в статус-баре.
- SEO: `sitemap.ts`, `robots.ts`, OG-изображения (`opengraph-image.tsx`), JSON-LD.
- Производительность: Motion только там, где нужен; аудит Lighthouse; бюджет шрифтов.
- Тесты: Playwright (навигация, клавиатура, reduced motion), axe-аудит доступности.
